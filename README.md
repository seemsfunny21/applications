# Applications — Οι εφαρμογές μου

Μια συγκεντρωτική εφαρμογή PWA με έξι καρτέλες στο επάνω μέρος. Οι πρώτες πέντε καρτέλες ανοίγουν ανεξάρτητες εφαρμογές, ενώ η έκτη συγκεντρώνει δύο παιχνίδια:

- [Ποδηλασία](https://seemsfunny21.github.io/voltes/)
- [Δρομολόγια](https://seemsfunny21.github.io/douleia/)
- [Υπενθυμίσεις](https://seemsfunny21.github.io/reminder/)
- [Pegasus](https://seemsfunny21.github.io/seemsfunny/)
- [Parking](https://seemsfunny21.github.io/Parking/)
- **Παιχνίδια**
  - [SudokuFunny](https://seemsfunny21.github.io/sudokufunny/)
  - [ReversiFunny](https://seemsfunny21.github.io/reversifunny/)

## GitHub Pages
Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main, Folder: / (root) → Save.

Website: https://seemsfunny21.github.io/applications/

## Εγκατάσταση σε Android
Άνοιξε τη διεύθυνση στο Chrome και επέλεξε ⋮ → Προσθήκη στην αρχική οθόνη / Εγκατάσταση.

Οι έξι εφαρμογές παραμένουν ανεξάρτητες. Τα SudokuFunny και ReversiFunny αποθηκεύουν τις παρτίδες τοπικά και λαμβάνουν εντολή παύσης όταν αλλάζεις καρτέλα ή παιχνίδι στο Applications. Αν ένα παιχνίδι είναι ανοιχτό, πάτησε ξανά «Παιχνίδια» για να επιλέξεις άλλο. Μη διαγράψεις την εγκατάσταση των Υπενθυμίσεων χωρίς να ελέγξεις πρώτα τις push ειδοποιήσεις.
